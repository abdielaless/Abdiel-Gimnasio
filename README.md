# Abdiel · Gimnasio

App web personal con cinco días de rutina, registro por serie, mapa corporal, temporizador, historial y apariencia clara/oscura.

## Publicación en GitHub Pages

1. Crea un repositorio público en tu cuenta de GitHub.
2. Sube los archivos de esta carpeta directamente a la raíz de la rama `main` (incluye `index.html` y `.nojekyll`).
3. En Settings → Pages selecciona Deploy from a branch, rama `main`, carpeta `/ (root)` y guarda.
4. Abre la URL que GitHub muestre al terminar el despliegue.

No hace falta compilar ni añadir claves o variables de entorno. Los enlaces a recursos son relativos para funcionar bajo la ruta del repositorio.

## iPhone

Abre el enlace publicado en Safari. Puedes añadirlo a la pantalla de inicio desde Compartir. La aplicación no solicita iniciar sesión.

## Datos

Los registros se guardan solo en el navegador y origen web actuales, sin sincronización automática. Historial permite exportar e importar respaldos JSON. Los datos guardados en Sites o localhost no aparecen automáticamente en GitHub Pages.

El código público incluye la rutina predefinida. No incluye sesiones personales, fotos, PDF de salud ni el historial del chat. Las alertas del temporizador pueden quedar suspendidas con la pantalla bloqueada. No hay soporte offline garantizado.
